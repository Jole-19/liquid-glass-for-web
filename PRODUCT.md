# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
React developers building web interfaces. It is a general-purpose library meant for any kind of project where high-fidelity glassmorphism is desired.

## Product Purpose
To provide a React component library built on a portable CSS glass material, with an optional WebGL refraction tier. It enables glass that behaves like real physical glass (saturated backdrop, asymmetric rim light, inset specular, real microtexture).

## Positioning
A component library providing true optical refraction and physical depth simulation (WebGL + CSS) that standard CSS-only `backdrop-filter` UI kits cannot easily replicate.

## Operating Context
Used by developers within React/Vite codebases. Evaluated via the interactive showcase/documentation site.

## Capabilities and Constraints
React 18/19 compatible. Uses `@ybouane/liquidglass` for optional WebGL refraction effects. No explicitly decided constraints on project types.

## Brand Commitments
"Liquid Glass for Web"

## Evidence on Hand
Component implementations (Button, Card, Input, Modal, Navbar, Switch, Tabs, Tooltip) exist in `src/lib/components/`. A live showcase site is available at `src/site/`.
